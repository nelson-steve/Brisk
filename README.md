# Brisk Engine
An open-source, C++20 game engine focused on modern rendering and GPU optimization.

## Features
- **Infinite Perspective Matrix**
- **Clustered Lighting**
- **Deferred Rendering**
- **Meshlet Rendering (Indirect Draw)**
- **Mesh Processing**: Using `meshoptimizer`.
- **Cascaded Shadow Maps**

## Graphics APIs
- **Vulkan** (Primary)
- **DirectX12** (Partial)

## Platforms
- **Windows**
