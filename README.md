# Brisk Engine
An open-source, C++20 game engine focused on modern rendering and GPU optimization.

## Features
- **Infinite Perspective Matrix**: Improved depth precision for large scenes.
- **Clustered Lighting**: Efficient handling of many dynamic lights.
- **Deferred Rendering**: High-quality lighting with minimal performance cost.
- **Meshlet Rendering (Indirect Draw)**: Optimized rendering for detailed models.
- **Mesh Processing**: Uses `meshoptimizer` for faster load times and reduced memory.
- **Cascaded Shadow Maps**: Realistic shadows for large environments.

## Graphics APIs
- **Vulkan** (Primary)
- **DirectX12** (Partial)

## Platforms
- **Windows**
